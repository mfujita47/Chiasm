# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.1.0] - 2026-02-07

### Removed
- Left-side accent (short thick lines) from `h1` header underlines across all slide types.

### Changed
- Unified the thickness of major structural lines to `1.5px` for a more consistent and refined appearance.
  - Affected elements: `h1` underlines (standard and title), 2-column vertical dividers, and image borders.
- Removed the gap above the vertical divider in 2-column slides by adjusting padding.


## [1.0.0] - 2026-02-04

### Added
- Initial release of the Chiasm theme.
- Support for `title`, `subTitle`, and `twoColumns` classes.
- Rich components: `box` (blue, green, yellow, red), `tag` (main, accent), `uparrow`, `downarrow`.
- Automatic pagination with customized design.
- Border and center alignment support for images.
- Integration of Google Fonts: Inter, BIZ UDPGothic, and Source Code Pro.

### Changed
- Improved layout and styling based on the Canyon theme.
- Optimized padding and margin for 2-column slides.
